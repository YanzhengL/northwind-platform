# Architecture

See the diagram in `docs/diagrams/architecture.png` (generated by `make diagram`).
Decisions and trade-offs are recorded in `docs/adr/`.

## Layers
1. AWS Organization - management, shared-services, workloads-dev, workloads-prod
2. Network - VPC per environment, 3 AZs
3. EKS cluster - Karpenter, LB controller, Pod Identity
4. Platform services - observability, policy, secrets, cost (Argo CD)
5. Tenant self-service - `teams/*.yaml` -> `terraform/modules/tenant`
6. Workloads - orders-api, payments-worker
